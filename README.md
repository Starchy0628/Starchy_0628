---

## 🔬 Current Research

**Nudge-Based Driver Attention Allocation in Human-Machine Co-driving**

In human-machine co-driving scenarios, drivers maybe over-trust autonomous systems and shift attention away from driving. I model this as an intertemporal utility trade-off under cognitive resource constraints, and design two nudge interventions — a **cognitive nudge** (real-time System Performance Index on HUD) and a **composite nudge** (SPI + peripheral dynamic halo for bottom-up attention capture) — tested in a 3×2 between-subjects experiment.
